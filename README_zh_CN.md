# Vyrax

由 Amyrax 开发，基于 FLClash 和 Mihomo 的代理客户端。

[English](README.md) · [下载](https://github.com/AmyraxVPN-Main/Vyrax/releases) · [问题反馈](https://github.com/AmyraxVPN-Main/Vyrax/issues) · [Telegram](https://t.me/AmyraxVPN)

当前验证的发布目标为 Windows x64，版本为 0.2.0，提供安装程序及 ZIP。
支持剪贴板导入、订阅链接、手动选服和 Fastest 自动选择。
更新检查使用 Vyrax 的 GitHub 稳定版本页面。

构建步骤和兼容性说明请参阅 [English README](README.md) 及
[品牌与数据兼容性说明](docs/vyrax-branding.md)。
